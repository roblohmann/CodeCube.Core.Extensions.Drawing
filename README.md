# CodeCube.Core.Extensions.Drawing

Set of extension methods to perform image operations.

> **Windows only.** This library is built on `System.Drawing.Common`, which is only supported on Windows since .NET 6. The assembly is marked with `[SupportedOSPlatform("windows")]`; using it on Linux or macOS raises a CA1416 warning at compile time and a `PlatformNotSupportedException` at runtime.
